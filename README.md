# Classroom — School Management

A lightweight school-management web app starter for managing student and teacher directories.

## Run it

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Included

- Dashboard with student, teacher, class, and total-record counts
- Student directory with class/grade details
- Teacher directory with subject details
- Add, edit, delete, and search records
- Responsive layout for desktop and mobile
- Browser `localStorage` persistence

## Important

This starter stores data only in the current browser. It has no user authentication, shared database, backups, or server-side security, so it is a prototype—not suitable for storing real student information. A production system should add a secure backend, role-based access, database backups, and appropriate privacy protections before real school data is entered.
